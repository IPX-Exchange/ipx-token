# IPX Exchange

The OS for the creator economy. IPX Exchange is a platform where creators raise production funding and each project's token then trades, on Base.

Operated by IPX Exchange, Inc. · [www.ipx.exchange](https://www.ipx.exchange) · support@ipx.exchange

## What IPX does on the platform

- **Routing asset:** every purchase on a project's market routes through IPX.
- **Graduation collateral:** the IPX collected during a raise pairs with the project's token to open its market.
- **Quote currency:** a graduated project's token trades against IPX.
- **Staking:** IPX stakers can claim a share of what the Protocol Vault receives. The amount varies with activity and there is no guaranteed return.

Team and investor allocations vest on-chain. Only part of the supply is unlocked at the start of the vesting clock.
